# Test assets

Only synthetic or anonymized fixtures may be committed.

Planned folders:

- `templates/minimal`: smallest valid placeholder template;
- `templates/branded`: anonymized representative template;
- `templates/broken`: intentionally invalid packages and placeholders;
- `markdown`: supported syntax and edge cases;
- `models`: valid and invalid model fixtures;
- `images`: small local images with known dimensions;
- `golden`: normalized OOXML expectations, never customer documents.

Binary DOCX changes require a fixture description and visual/structural
verification notes in the pull request.
