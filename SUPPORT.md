# Support

Use the following channel for each kind of request:

- usage question or idea: GitHub Discussions, when enabled;
- reproducible bug or feature request: GitHub Issues;
- security vulnerability: the private process in `SECURITY.md`;
- conduct concern: the private process in `CODE_OF_CONDUCT.md`.

Before requesting help, run `docxgen --version`, retry with `--json`, and
include the command, exit code, diagnostics, operating system, and a minimal
synthetic input. Do not upload confidential templates or documents.

The project is maintained on a best-effort basis. Community support does not
include guaranteed response times, custom template design, or recovery of
corrupted customer documents.
