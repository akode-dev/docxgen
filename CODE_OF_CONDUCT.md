# Code of Conduct

DocxGen is committed to a welcoming, respectful, and productive community.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss ideas and code without attacking people.
- Respect different backgrounds, identities, experience levels, and
  communication styles.
- Give actionable feedback and accept it in good faith.
- Protect private, confidential, and security-sensitive information.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing, sustained disruption, and publishing private
information without permission are not tolerated in project spaces.

## Enforcement

Maintainers may edit or remove comments, commits, issues, discussions, and
other contributions that violate this code. Repeated or serious violations may
result in a temporary or permanent ban.

Report conduct concerns privately to the maintainers through the contact
method listed in the GitHub repository profile. Reports will be reviewed as
confidentially and promptly as practical. Maintainers who have a conflict of
interest must recuse themselves from handling the report.

This code applies in all project spaces and when a person officially
represents the project.
